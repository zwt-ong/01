# 01 / 原创观点发现

一个在本地运行的信息工作台：发现最近 7 天个人创作者提出的新想法，关注 AI、个人 IP、创业，也保留跨领域的方法和实践。界面延续 01 黑白主题。

[GitHub 源代码](https://github.com/zwt-ong/01) · [自动检查](https://github.com/zwt-ong/01/actions/workflows/checks.yml) · [配置指南](docs/SETUP.md) · [API 与本地模型入门](docs/API_AND_MODELS.md)

## 0.3 中文平台作品收集

新增左侧“抖音 / B站”工作台，围绕 vibe coding、AI 编程复盘和独立开发实践配置中文搜索入口与参考作者主页。

- 粘贴作品分享文案或链接即可加入观察。B站作品可尝试读取标题、上传者、原始时间和时长；短链接的跳转限制在对应平台内。
- 抖音暂支持作品链接收集。读取不到原始时间时明确标记待补，不把添加时间当作发布时间。
- 保留首次发现、私人笔记和现有原文整理流程；平台自制标记不替代本人原作确认。
- 搜索结果在对应平台打开，作者主页供用户查看。**后台自动追新及自动全站发现尚未接通。**

详细步骤和当前限制见 [抖音 / B站工作台](docs/CHINESE_PLATFORMS.md)。

## 0.2 的变化

原来的媒体、营销资讯订阅默认停用。先发现本人原作候选，再阅读证据和整理观点。每张卡包含：**谁提出 → 核心观点 → 有什么新意 → 依据或实践经历 → 原始时间与链接 → 可以怎样验证或使用**。

- 原始发布范围为最近 7 天；首次发现单独持久化，今日首次发现有标记。
- 当前默认读取 Simon Willison 的个人长文章、张鑫旭的个人实践博客、Ethan Mollick 的个人博客；没有近期内容时留空。
- YouTube 官方关键词搜索发现陌生创作者，需要用户配置免费 API 密钥；每天相同关键词缓存，最多 6 个关键词各取一页。
- 明显搬运、切片、汇编和卖课标题做规则过滤。简介有推广信号会提示；作者有业务本身不导致封禁。
- 可手动补原文、字幕和六字段，或使用已经安装的本地 Ollama 模型整理。程序不会安装模型或把私密文本发给云模型。
- 标题和视频简介留在候选，不冒充完整观点。模型引文必须存在于输入文本；输出仍标记待人工核对。
- 作者屏蔽可撤销；历史日报、收藏、验证笔记、搜索、方向筛选和 Markdown 导出保留。

**当前尚未完成的覆盖：** 抖音和B站没有后台自动作者追新或全站发现；B站单条作品资料可尝试读取，小红书仍为手动原作链接。各视频平台的字幕尚未自动获取。关键词筛选不是全网搜索覆盖，也不能保证准确识别所有原创或广告。

## 启动与更新

需要 Python 3.10 或更新版本，没有第三方 Python 包依赖。Windows 双击桌面的 **01** 或项目目录中的 `start.cmd`，打开 `http://127.0.0.1:8765`。聊天内文件预览不会执行启动。

```sh
python app.py serve
```

已有服务时启动器复用它；新服务在后台运行。手动点“更新日报”，生成截至当前时刻的七天候选。模型整理可能增加等待时间；页面显示当前进度。旧的 0.1 日报保留在历史中。

若端口被其他程序占用：`python launch.py --port 8766`。

## 每天北京时间 00:00

应用运行时每分钟检查，午夜生成以当天 00:00 为终点的滚动七天日报；启动时补跑上一期。电脑需要开机、联网。睡眠或关机期间本地方案无法保证采集。

可选的 Windows 任务保持原任务名 `OpportunityRadar-Daily`：

```powershell
.\install_schedule.ps1
```

任务以当前已登录用户的普通权限运行，直接使用 `pythonw.exe`，不修改系统执行策略。已有同名任务默认不覆盖；升级程序不需要重新注册任务。删除自己的任务用 `-Remove`。

仅采集、不打开浏览器：

```sh
python app.py collect --scheduled
```

## 配置和费用

博客候选可以直接使用。YouTube 自动发现和模型整理分别按 [配置指南](docs/SETUP.md) 设置。密钥仅填写在本地页面，不发送给聊天；模型下载占用数 GB，速度和整理质量需要在自己的电脑实际测试。

标题和短节选可用 MyMemory 免费翻译；最多每天 4,000 字符并缓存，失败保留原文，来源不变。只有公开标题与至多 180 字符的摘录发送给翻译服务，私密原文、收藏和笔记不发送。可以关闭翻译。

不使用付费模型或收入预测。第三方服务可能故障、限流或调整额度；状态会显示配置和连接缺口。可查看 [YouTube 官方配额说明](https://developers.google.com/youtube/v3/getting-started) 与 [MyMemory 文档](https://mymemory.translated.net/doc/spec.php)。

## 数据和证据

自动博客原文只作为临时的本地分析输入，不持久保存全文；数据库存短节选、原始时间和链接。用户自行粘贴的原文、字幕、观点编辑和验证笔记保存在本机。原文可能是节选，模型也可能概括错误。

个人发布页面不是观点正确性的证明。所谓新意是相对差异，不宣称世界首创；原文引文匹配只能证明引用存在，不能证明概括得到支持或实践有效。验证动作是建议，不是作者已经做过的实验或收益保证。

`data/`、`config.local.json`、`.env`、`work/` 都被 Git 忽略。公开仓库仅提交代码、默认空凭证配置、测试和开发记录。旧数据库升级采用新增表，不删除历史资料。服务只监听本机，写请求验证令牌、Host 和 Origin，网页动态文本转义。

```sh
python -m unittest discover -s tests -v
node --check web/app.js
node --check web/ideas-ui.js
node --check web/platforms-ui.js
node tests/frontend-smoke.cjs
```

测试使用隔离数据库和模拟网络，不消耗真实 API 配额。前端检查覆盖候选/六字段呈现和文本转义，不能替代真实浏览器的视觉验收。实际 YouTube 密钥与模型运行需配置后另行验证。
