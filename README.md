# 机会雷达 / Opportunity Radar

一个免费运行在本地的每日信息工作台：关注商业机会、AI 动态，以及自媒体与个人 IP。用真实来源发现变化，用小实验验证需求。

第一版的验收目标是自动生成一份有来源、可查看、可导出的中文日报。机会卡是待验证的商业假设，不代表收益预测。

## 启动

需要 Python 3.10 或更新版本。不需要安装第三方 Python 包，不需要 API 密钥。

Windows 用户双击 `start.cmd`，浏览器将打开 `http://127.0.0.1:8765`。保持启动窗口打开；关闭窗口会停止网页服务。

也可以在项目目录运行：

```sh
python app.py serve
```

点击“更新日报”，生成截至当前时刻的最近 24 小时简报。第一次通常需要 1～2 分钟；网络和翻译服务可能影响速度。

若端口已占用，可以打开已有服务，或用 `python app.py serve --port 8766` 启动另一个端口。

## 每日北京时间 00:00 更新

应用自带定时器：运行时每分钟检查一次，午夜生成刚结束的自然日的日报。启动时若没有上一日的日报，会补跑；不会补造更早日期的数据。

可额外安装 Windows 计划任务，使网页未打开时也能采集：

```powershell
.\install_schedule.ps1
```

任务名为 `OpportunityRadar-Daily`，以当前已登录用户的普通权限运行。后台直接使用 Python 自带的 `pythonw.exe`，不弹出终端，不依赖 PowerShell 脚本执行策略。安装命令需在允许执行本地脚本的环境运行；不要为了安装修改系统安全策略，可由协作开发助手完成注册。

只注册这个任务，不修改其他任务或系统执行策略。已有同名任务时默认不覆盖。脚本把北京时间转换为本机时间；本机时区存在夏令时则拒绝安装，使用应用内定时器即可。

电脑需开机、联网且用户已登录。休眠或关机错过时间后，可用时尝试补跑。没有注册计划任务时，需要保持网页服务运行；本地方案不能保证关机期间采集。计划任务失败会每隔 15 分钟重试，最多 3 次。

仅采集，不打开网页：

```sh
python app.py collect --scheduled
```

移除自己安装的任务：

```powershell
.\install_schedule.ps1 -Remove
```

## 第一版功能

- RSS/Atom 并发采集、超时和一次重试；逐来源记录状态。
- 北京时间的严格 24 小时时间范围；无新内容时显示空状态。
- AI、商业应用、个人 IP 分类；按相关度和发布时间排序。
- URL 与相似标题去重；保留原文链接与发布时间。
- 免费翻译英文标题与短摘录；失败时保留原文并标记。
- 真实来源日报、历史记录、Markdown 导出、搜索与方向筛选。
- 收藏、验证笔记、手动加入其他平台的链接。
- 多来源候选机会卡，展示已有线索、缺少的证据和小规模验证动作。
- 本地数据存储；个人设置、笔记、收藏和日报不进入 GitHub。

## 信息源和费用

初始启用：爱范儿、少数派、OpenAI、Hugging Face、Google AI、YouTube 官方博客、Buffer、Social Media Examiner。36 氪首次验证返回非 RSS 内容，默认停用。

第一版没有自动搜索 YouTube 视频，也未接入抖音、TikTok 热榜。可先手动添加平台链接。信息源开关在网页设置中，来源定义在 `config.example.json`。

英文翻译使用 [MyMemory 公开翻译接口](https://mymemory.translated.net/doc/spec.php)。其文档列明匿名免费额度为每日 5,000 字符；本应用用 UTC 日期记录自己的计数，上限设为 4,000 字符，并缓存成功翻译。提供方可能有额外限制、共享 IP 配额或故障，不保证可用。

翻译时仅发送公开标题和至多 180 字符的公开 RSS 摘录，不发送收藏笔记或其他个人数据。不需要信用卡、付费模型或登录翻译服务。可在设置中关闭翻译；已缓存译文仍可使用。原文始终保留。

## 数据与证据边界

摘要是最多 220 字符的订阅源短摘录，不是大模型读完文章后的总结。文章正文和视频未被抓取。可能出现不完整摘录、机器翻译错误或来源自身的观点。

目前的排序是兴趣相关度和新鲜度，未取得播放量、搜索量或全平台热度。去重主要依据 URL 与高度相似的标题，跨语言、不同措辞的同一事件仍可能重复。

机会卡要求至少两个不同自动信息源出现相关内容。相似主题的多个文章不证明市场需求，更不证明客户已付费。卡片明确标记为“线索级／待验证”，提供具体的用户访谈、样例试用和继续条件，不编造客户、交易或收入。手动内容未被核实，不计作独立商业证据。

## 项目结构

```text
app.py                    本地服务、接口和定时器
radar/core.py             采集、分类、去重、翻译、数据库、日报
web/                      网页界面
config.example.json       可公开的默认配置
config.local.json         个人配置（首次改设置后产生，Git 忽略）
data/                     数据库、日报、任务日志（Git 忽略）
tests/                    离线测试，不请求真实服务
docs/                     需求、开发记录和后续路线
.github/workflows/        提交后的自动检查
```

服务只监听 `127.0.0.1`；写操作需要页面取得的令牌，并验证 Host 和 Origin。动态文本在网页上转义，拒绝非 http/https 原文链接。

## 检查

```sh
python -m unittest discover -s tests -v
node --check web/app.js
```

Node 只用于开发检查，使用应用无需 Node。测试覆盖订阅源解析、时间窗口、去重、机会证据门槛、翻译降级与数据保存。持续开发过程见 [开发日志](docs/DEVLOG.md)，后续范围见 [路线图](docs/ROADMAP.md)。
