# 抖音 / B站工作台

本轮把中文平台作品收集放进 01，优先围绕 vibe coding、AI 编程复盘和独立开发实践。当前版本提供平台搜索与作者主页入口、作品分享导入、B站公开作品资料读取。**尚未实现后台自动追踪任意作者或自动读取全站搜索结果。**

## 使用步骤

1. 打开 01，点击左侧“抖音 / B站”。
2. 在“发现陌生作者”点击对应平台的搜索入口。默认使用简短方向词；可自行修改，每行一个，最多 6 个。
3. 在平台找到作品后，复制它的分享链接或分享文案，粘贴到“收集抖音 / B站作品”，每次一条。
4. 点击“读取资料并加入观察”。B站作品可尝试自动取得标题、上传者、原始时间和时长；抖音暂收集链接，可填写标题和实际提出者。
5. 在“我的观察”阅读原作，核对提出者，再补充原文或字幕，继续使用已有的六字段整理功能。

B站支持完整 BV 视频地址和可正常跳转的 b23.tv 分享地址。抖音支持完整作品地址和可正常跳转的分享短链。分享中的跟踪参数会被去除，跳转只能留在对应平台的受支持域名内。

## 参考作者

可保存作者名称以及 B站、抖音的本人主页。尚未知道主页时，先使用姓名搜索入口查找；同名、搬运或切片账号不能当作本人。确认后填入主页地址，便于直接打开查看最新作品。

参考作者配置仅保存在本地。保存主页地址是建立查看入口，不代表已经取得作者授权或接通自动追新。

## 原始时间和证据

- B站读取到原始发布时间时，用该时间判断是否属于最近 7 天。旧视频仍可保存为参考，不填充本期日报。
- 抖音或读取失败的内容只记录添加时间，不自动推断原始发布时间，也不进入七天新内容。
- 作品资料读取失败时保留链接并显示信息待补；重导入已有作品时保留私人笔记和首次发现时间，读取失败不覆盖之前已获得的资料。
- B站的平台“自制”标记只是线索，不能证明上传者就是观点提出者。作品导入不会自动生成观点卡；仍须核对原作并补充原文或字幕。
- 已取得原始时间的导入内容，在下次更新日报时参与现有七天候选筛选。

## 为什么全自动接入尚未完成

本机实测单条 B站公开视频资料可以读取，但作者主页动态请求返回访问限制。当前作品资料读取是尽力能力，可能受平台调整或限制影响；失败时降级为仅收集链接，不绕过访问限制。

抖音官方搜索产品页提供申请内测入口，并要求审批通过后接入；其能力文档仍保留实验能力说明。应用不能据此假设普通 API 密钥即可获取全站内容。[官方申请入口](https://developer.open-douyin.com/product/search)、[能力说明](https://developer.open-douyin.com/docs/resource/zh-CN/dop/ability/search-management/item-search)

后续全自动能力需要先验证应用实际获得的接口权限和数据使用范围。YouTube 原有搜索与个人博客来源继续可用；它们与本工作台的浏览器搜索入口是不同的数据渠道。

## 2026-10-15 · 浏览器助手测试版

正常浏览器已验证两平台搜索、作者作品列表和视频原始时间的读取。项目提供浏览器助手测试版，位于 browser-helper；在 01 页面可以下载源码包并配置本地配对。原有分享工作台不需要扩展，助手队列则需用户安装、配对与首次真实验收。安装前阅读 [权限和步骤](../browser-helper/README.md)。

助手只向本机发送作品资料；作品链接和追踪主页需对应，不接受平台生成的 AI 章节摘要作为作者原文。配对可以撤销，不提供原来的管理权限。首次安装、持续运行和每日任务仍待验收，不能由正常网页单次读取推断稳定全自动接入。
