# API 与本地模型入门

01 将两项能力连接起来：通过 YouTube API 找到近期内容，用本地模型整理已经取得的原文。当前使用现成的 Qwen3 模型；安装、下载和配置属于部署，处理文章属于推理。

## 1. API 是程序获取信息的接口

人可以打开 YouTube 网页搜索，程序可以向 YouTube Data API 发出查询，得到便于处理的数据。API Key 是识别调用项目的凭证，服务方据此管理调用权限和配额。

01 的搜索要求包括关键词、发布时间范围和最新优先排序。当前最多使用 6 个中英文关键词，每个关键词取一页、最多 25 条；当天成功的相同关键词搜索会复用缓存。

配置流程：

1. 在 Google Cloud 创建项目，用来管理服务、凭证和配额。
2. 启用 YouTube Data API v3。
3. 创建 API 密钥，并将 API 限制设为仅允许 YouTube Data API v3。
4. 在 01 的本地设置中填写密钥并保存。
5. 更新日报，检查搜索状态与候选结果。

密钥保存在被 Git 忽略的 `config.local.json`。公开示例配置不含真实凭证。操作细节见 [配置指南](SETUP.md)，接口原理见 [YouTube 官方说明](https://developers.google.com/youtube/v3/getting-started)。

**搜索结果只提供标题、简介、作者和时间等信息。** 当前程序不会通过搜索接口获得完整视频字幕，因此搜索成功的内容仍是候选；需要补充原文或字幕，才能整理其观点。

## 2. Ollama 和模型分别负责什么

| 名称 | 作用 |
| --- | --- |
| Ollama | 加载和管理模型，并提供供程序调用的本机接口 |
| Qwen3 | 根据输入文字生成回答的已训练模型 |
| 模型文件 | 保存在硬盘上的模型数据，运行时需要加载到内存或显存 |
| 提示词 | 每次调用时给模型的任务要求，例如按固定字段整理原文 |

`qwen3:8b` 表示约 80 亿参数规模的模型，当前 Ollama 分发版本约 5.2 GB；参数规模不等于文件大小，也不能单独保证概括质量。模型需要结合实际硬件和原文测试。[模型说明](https://ollama.com/library/qwen3:8b)

部署流程是安装 Ollama、下载模型、启动服务，然后在 01 中选择已下载的模型并检测连接。常用命令如下：

```powershell
# 下载模型；已经下载完成时无需重复操作
ollama pull qwen3:8b

# 与模型直接对话
ollama run qwen3:8b

# 查看本机已下载的模型
ollama ls
```

公开默认配置保留 `qwen3:4b`，供不同设备选择；本次实际使用环境已经切换到 8B。01 不会自动下载安装运行时或下载模型。[Ollama 命令说明](https://docs.ollama.com/cli)

## 3. 01 也通过 API 调用本地模型

| 接口 | 请求去哪里 | 用途 |
| --- | --- | --- |
| YouTube Data API | Google 的服务器 | 联网搜索公开内容 |
| Ollama `/api/chat` | `http://127.0.0.1:11434` | 在本机整理输入的原文 |

`127.0.0.1` 指这台电脑自己。本地 Ollama 接口无需 API 密钥；01 固定连接本机并拒绝远程模型配置。[接口说明](https://docs.ollama.com/api/introduction)

流程为：

```text
关注方向 → API 搜索 → 视频候选 → 补原文或字幕
                                     ↓
个人博客原文 ──────────────────→ 本地模型整理
                                     ↓
                        引文检查与原文一致性复核
                                     ↓
                           观点卡：待人工核对
```

作者、原始时间和链接来自来源信息；模型整理核心观点、新意、依据和使用建议。程序要求结构化输出，核对引文是否存在，并再次检查摘要是否得到原文支持。失败时保留候选，成功后仍需要人工核对。作者的个人经历也不能自动当作普遍有效的证明。

联网搜索、博客订阅和已启用的标题/短摘录翻译，与本地模型推理是不同环节。各环节的数据范围见 [README](../README.md)。

## 4. 一个简单练习

运行 `ollama run qwen3:8b` 后，输入：

> “AI 让一人公司变得可行。”请拆出这句话的核心观点、缺少的证据，以及一个低成本验证办法，不要补造事实。

观察模型是否区分已有信息和待验证的推断。01 的观点整理也是“输入材料和要求 → 模型推理 → 检查结果”的过程。给模型一篇新文章作为输入，不会自动改变它的模型参数或重新训练它。
