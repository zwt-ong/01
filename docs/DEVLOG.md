# 开发日志

## 2026-10-13 · V0.1

从宽泛的跨平台热点收集，收敛成一个有真实来源的本地日报。先采用可验证的 RSS/Atom 接口，不让尚未解决的平台权限阻碍第一个版本。

验证了 8 个可用订阅源。36 氪返回的内容无法按订阅源解析，默认停用；未通过证书验证的来源没有通过关闭 TLS 验证来接入。

实现严格的北京时间窗口、逐来源超时和重试、SQLite 保存、标题与 URL 去重、免费翻译与缓存。英文翻译保留原文，来源摘录和商业假设分开呈现。

实现本地网页、方向筛选、搜索、历史、导出、收藏、验证笔记与手动链接。界面采用深绿导航和浅色阅读区，适配窄屏。

发现初版把综合科技来源里的普通硬件内容也当作 AI，随后收紧分类规则；修复英文 `app` 误匹配 `Apple` 的问题。内容少时保留真实数量，不使用旧新闻填充。

测试发现 SQLite 的普通 `with` 语句只处理事务、不关闭连接；改成显式关闭的上下文管理器，修复 Windows 上的文件锁问题。

18 项测试通过，其中 14 项验证核心数据处理，4 项使用独立临时数据库验证本机 HTTP 交互。真实运行验证：8/8 个启用来源采集成功；生成一份上一自然日的日报，以及一份最近 24 小时简报。页面、脚本、样式、日报状态和 Markdown 导出均返回 HTTP 200；无令牌写请求和外部 Host 请求被拒绝。

午夜 Windows 任务首次试跑遇到系统禁止 PowerShell 脚本执行的问题。将后台任务改为直接运行 Python 自带的 `pythonw.exe`，保持无窗口执行，不修改系统执行策略。日报采集结果会写入本地任务日志。

修复后后台试跑成功：计划任务返回码为 0，8/8 个来源采集成功；下一次执行时间为北京时间 2026-10-14 00:00。首次验收的最近 24 小时简报保留 7 条相关内容，没有凑数。

浏览器工具的安全策略阻止访问本地预览，未完成自动视觉检查；不把 HTTP 检查表述为浏览器交互验收。首次使用仍需人工检查页面显示与阅读体验。

后续首先评估日报噪声和机会卡的实际帮助，再决定扩展数据来源和模型分析。

## 2026-10-13 · 启动体验修复

## 2026-10-14 · 原作发现与六字段观点卡

用户反馈媒体/营销源偏离所需内容：希望发现近期个人创作者的新观点，重视解释与实践，允许跨领域。由 24 小时资讯汇总改为最近 7 天原作候选；原始发布与首次发现分开保存，今日首次发现单独展示。旧配置自动切换来源，历史报告和私人笔记保留。

新增个人博客原始订阅，使用 Simon Willison 的长文章 feed，避开链接与引用汇编。实现 YouTube 官方关键词搜索的陌生创作者发现、日缓存和缺密钥状态；目前未用真实密钥运行，离线响应测试不等于线上集成已验收。B站公开搜索返回访问限制，未绕过；抖音和小红书仍支持手动原作链接。

候选与观点卡分开；六字段、原文引文、本人原作确认、模型待核对、人工编辑和可撤销作者屏蔽进入网页。对标题中的明显切片/汇编/卖课做规则过滤，简介推广信号提示而非封禁整个作者。未读取字幕时不凭标题补完观点。

本地 Ollama 结构化输出接入已完成，固定本机地址并拒绝远程模型。尚未安装运行时或下载模型，因此未验证实际模型质量与速度；缺原文、服务失败、引文不存在时保留候选。引文匹配不是事实验证或语义正确性证明。

37 项 Python 测试与 Node 前端行为检查通过，覆盖既有功能、七天边界、首次发现持久化、配置迁移、缺依据降级、公开状态不泄露密钥、六字段编辑和屏蔽恢复。真实采集三个个人来源成功，七天内展示 4 条候选；其他来源过期的作品未填充本期。浏览器本地预览受工具策略限制，尚未完成视觉和真实浏览器交互验收。

## 2026-10-14 · 真实密钥与本地模型配置验收

用户完成 Google Cloud 项目、YouTube Data API 限制密钥和本地填写。真实关键词搜索成功，返回 29 条七天内视频候选；密钥始终留在私人配置中。搜索可用不代表原作身份、字幕或观点质量已通过验收。

用户安装 Ollama 并下载 qwen3:4b，确认本地服务和 GPU 加载。首次完整整理超时；短节选测试发现模型复述字段定义。改为明确的原文阅读任务、简短输出、原文句子引文约束、字段占位拦截，以及长输入的有标记节选。随后真实原文结构化生成约 4～8 秒，单机结果不能作通用速度保证。

人工查看测试输出发现概括可能遗漏后续键盘审查或夸大完成范围，因此增加第二次本地原文一致性复核。实际测试中不合格概括被拒绝，没有覆盖原有人工示例。小模型即使通过检查仍需人工阅读；本次验证证明服务可运行与降级有效，不证明筛选和概括质量已经达标。

新增输入/占位回归、有真实引文但概括不一致的拒绝测试，以及本地服务复用与占用端口防护，合计 42 项 Python 测试；前端行为与语法检查保留。运行输入和模型结果仅在本地，不提交。

用户选择将模型存储迁到 D 盘并测试 qwen3:8b。复制后逐文件核对 SHA-256，确认运行时能读取，再清理原 C 盘模型副本。图形启动器首次重启没有启动 API 服务，因此使用本机后台服务，并在采集程序加入仅对已安装运行时的按需启动；读取用户级模型路径，不安装或自动下载模型。

8B 下载完成后，完整个人原作通过中文六字段、引文匹配和模型一致性复核，首次测试约 29 秒。这只验证了一篇样本，概括仍需人工核对。用户私人配置切换到 8B，公开默认配置继续保留较小模型供其他设备选择。
