# 第一版需求

目标：每天从中英文公开信息中生成一份有来源的中文日报，并支持商业机会观察。优先级为商业机会、AI 动态、个人 IP 与内容选题。

范围：以中国市场为主，参考海外变化；关注 AI 服务、小工具与软件、创作者业务。第一版零订阅费用、无需 API 密钥、运行在本地浏览器。

每日北京时间 00:00 更新上一自然日的日报；手动更新读取最近 24 小时。每份最多 10 条相关资讯、最多 3 张机会卡。证据不足时不生成卡片。预算未确定时，验证动作优先用户访谈和小样例。

必须完成：真实来源采集、24 小时筛选、来源链接与时间、中文展示、持久化、历史与导出、失败状态可见。初期英文翻译采用免费服务，故障和额度不足时明确保留原文。

质量观察：资讯是否有帮助、筛选是否有噪声、机会卡是否能形成可执行实验。选题质量和商业机会质量需要用户使用反馈，不能由单次程序运行证明。

公开范围：代码、默认配置、开发日志；个人配置、收藏、笔记、日报和密钥不公开。

首版不包含自动抖音／TikTok 热榜、YouTube 视频搜索、大模型摘要、收入预测或保证、远程部署、手机推送。
