# 第一版需求

> 以下为 0.1 的历史范围。当前 0.2 按下方“原创观点改进”执行；历史日报继续保留。

目标：每天从中英文公开信息中生成一份有来源的中文日报，并支持商业机会观察。优先级为商业机会、AI 动态、个人 IP 与内容选题。

范围：以中国市场为主，参考海外变化；关注 AI 服务、小工具与软件、创作者业务。第一版零订阅费用、无需 API 密钥、运行在本地浏览器。

每日北京时间 00:00 更新上一自然日的日报；手动更新读取最近 24 小时。每份最多 10 条相关资讯、最多 3 张机会卡。证据不足时不生成卡片。预算未确定时，验证动作优先用户访谈和小样例。

必须完成：真实来源采集、24 小时筛选、来源链接与时间、中文展示、持久化、历史与导出、失败状态可见。初期英文翻译采用免费服务，故障和额度不足时明确保留原文。

质量观察：资讯是否有帮助、筛选是否有噪声、机会卡是否能形成可执行实验。选题质量和商业机会质量需要用户使用反馈，不能由单次程序运行证明。

公开范围：代码、默认配置、开发日志；个人配置、收藏、笔记、日报和密钥不公开。

首版不包含自动抖音／TikTok 热榜、YouTube 视频搜索、大模型摘要、收入预测或保证、远程部署、手机推送。

## 0.2 原创观点改进

目标：及时发现个人创作者提出的新想法，而不是汇总媒体和营销资讯。兴趣涵盖 AI、个人 IP、创业，同时保留跨领域的新概念、独特解释、个人实验和新应用。优先原作、新意、说服力和可实践性；不按播放量替代内容判断。

时间范围改为最近 7 天，原始发布时间与首次发现时间分开；今日首次发现单独标记。无日期、更新旧文、添加旧链接不能冒充今日发布。每日北京时间 00:00 更新，手动更新以当前时刻为窗口终点。

默认停用原来的媒体与营销订阅。个人博客为当前可用来源；YouTube 官方关键词搜索发现陌生创作者，需要用户配置免费 API 密钥。抖音、B站、小红书尚未接入自动采集，接受本人原作链接与用户提供的字幕。

先进入“发现候选”，再形成六字段：谁提出 → 核心观点 → 有什么新意 → 依据或实践经历 → 原始时间与链接 → 可以怎样验证或使用。只有标题或视频简介时不生成完整观点。可手动整理，或使用已安装的免费本地模型；模型须引用输入中真实存在的原文，并明确待人工核对。

过滤明显搬运、切片、资讯汇编和显式卖课推广标题。作者经营业务不构成整体封禁理由；简介推广信号单独提示。作者屏蔽可撤销，偏好保存在本地。

验收：真实来源状态、严格七天范围、首次发现持久化、六字段与引文核对、缺密钥/模型/字幕时不编造观点、私密配置不返回或提交、历史/收藏/导出继续可用。内容质量与自动筛选误判通过后续使用反馈评估。
