# 后续路线

## V0.1 · 真实日报

公开订阅源、本地网页、中文翻译、24 小时窗口、持久化、收藏与验证记录、机会观察。

## V0.2 · 提高相关度

根据使用反馈调整兴趣规则；增加排除词和自选来源；更准确合并不同语言和措辞的同一事件；记录被收藏和被忽略的内容。

## V0.3 · 持续机会观察

积累数周基线，跟踪同一具体需求的变化，分别呈现技术变化、用户求助、实际采购与交易证据。建立机会追踪状态，回看曾经的判断是否得到验证。

## V0.4 · 扩展平台与模型

评估 YouTube 官方视频 API；逐个平台验证合法、稳定的数据渠道。费用由使用者决定后，再增加可选模型摘要和更精细的商业分析。任何需要密钥的能力单独配置，不将凭证提交到仓库。

## GitHub 记录方式

每个能运行的功能形成一次提交，开发日志解释关键决定。公开默认配置与代码；本地运行数据不发布。先完成本地可验证的版本，再同步到使用者指定的仓库。
