# 后续路线

## V0.1 · 真实日报

公开订阅源、本地网页、中文翻译、24 小时窗口、持久化、收藏与验证记录、机会观察。

## V0.2 · 原创观点发现（已实现，完成一台设备的配置实测）

个人原始博客、七天窗口与首次发现、候选与六字段分离、作者屏蔽恢复；YouTube 陌生创作者关键词搜索和本地模型整理已接入。真实密钥和本地运行时已完成一次配置验收，仍需持续评估搜索噪声、原文概括、新意与实践价值。无字幕的视频先补原文；不把仅有标题的内容当作已读观点。

## V0.3 · 中文平台作品收集

中文搜索、参考作者主页入口、抖音分享链接导入与B站作品资料读取。原始时间未知保留为参考，原作身份和字幕继续核对。后台作者追新与陌生作者自动发现尚未接通；下一步先验证实际可用、允许使用的数据来源，再结合用户的正负样本校准筛选。

## 后续 · 持续机会观察

积累数周基线，跟踪同一具体需求的变化，分别呈现技术变化、用户求助、实际采购与交易证据。建立机会追踪状态，回看曾经的判断是否得到验证。

## V0.4 · 扩展平台与原文获取

逐个平台验证抖音、B站、小红书公开、稳定且允许使用的数据渠道，优先本人原作、可靠原始时间和合法字幕。改善误判与多语言去重，评估实际模型质量后调整模型。需要密钥的能力单独配置，不将凭证提交到仓库。

## GitHub 记录方式

每个能运行的功能形成一次提交，开发日志解释关键决定。公开默认配置与代码；本地运行数据不发布。先完成本地可验证的版本，再同步到使用者指定的仓库。
