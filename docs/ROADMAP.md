# 后续路线

## V0.1 · 真实日报

公开订阅源、本地网页、中文翻译、24 小时窗口、持久化、收藏与验证记录、机会观察。

## V0.2 · 原创观点发现（已实现接口，外部能力待配置验收）

个人原始博客、七天窗口与首次发现、候选与六字段分离、作者屏蔽恢复；YouTube 陌生创作者关键词搜索和本地模型整理已接入。下一步配置真实密钥和运行时，测试搜索噪声、原文概括、新意与实践价值。无字幕的视频先补原文；不把仅有标题的内容当作已读观点。

## V0.3 · 持续机会观察

积累数周基线，跟踪同一具体需求的变化，分别呈现技术变化、用户求助、实际采购与交易证据。建立机会追踪状态，回看曾经的判断是否得到验证。

## V0.4 · 扩展平台与原文获取

逐个平台验证抖音、B站、小红书公开、稳定且允许使用的数据渠道，优先本人原作、可靠原始时间和合法字幕。改善误判与多语言去重，评估实际模型质量后调整模型。需要密钥的能力单独配置，不将凭证提交到仓库。

## GitHub 记录方式

每个能运行的功能形成一次提交，开发日志解释关键决定。公开默认配置与代码；本地运行数据不发布。先完成本地可验证的版本，再同步到使用者指定的仓库。
